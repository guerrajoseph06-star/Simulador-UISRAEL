# Simulador UISRAEL - Examen Complexivo Contabilidad y Auditoría

Simulador offline de 1000 preguntas para el examen complexivo de Contabilidad y Auditoría de la Universidad Tecnológica Israel (UISRAEL) - Ecuador.

## Cómo instalar como app en tu celular

1. Abre Chrome en tu Android
2. Entra a: `https://TU-USUARIO.github.io/simulador-uisrael`
3. Chrome te mostrará un banner "Instalar app" — pulsa **Instalar**
4. Listo: el simulador aparece en tu pantalla de inicio como app
5. **Funciona 100% sin internet** después de instalado

## Características

- 1000 preguntas del área contable Ecuador (normativa 2025)
- Tributación, Auditoría, Costos, NIIF, Legislación y más
- Modos: Diagnóstico, Rápida, Estudio por materia, SRS, Examen 60 preguntas
- Filtros: Solo teóricas (670) / Solo prácticas (303)
- Pruebas de texto libre (27 preguntas abiertas)
- SRS inteligente basado en tus errores
- Cronómetro para examen simulado (90 min)
- 100% offline con Service Worker

## Archivos del proyecto

```
index.html      → El simulador completo (todo en un archivo)
manifest.json   → Configuración de la app (nombre, iconos, colores)
sw.js           → Service Worker (permite uso offline)
icon-192.png    → Icono de la app (pantalla inicio)
icon-512.png    → Icono grande (splash screen)
```
